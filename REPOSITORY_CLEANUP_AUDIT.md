# Repository cleanup audit and usage map

Baseline: `2eb40fd44b48baa31b31dcd1047ab89f8a128c3b`. This audit covers tracked
source/configuration/assets and all 20 originally reachable commits. The manuscript
and Supporting Information themselves were not provided; unique materials were
not deleted merely because they are outside the Quick Start.

## Canonicalization evidence

The original Compose file mounted `./src:/ws/src`. The latest CTVI changes (commit
`2eb40fd`) modified `src/gps_truck_nav/truck_bringup`; earlier root variants had
Sonoma parameters. Before cleanup, `colcon list --base-paths .` found each of
three packages twice. `truck_bringup` had 70 identical Git blobs, 14 differing
blobs (including eight LFS-versus-ordinary-Git image representations), seven
root-only meshes and one nested-only world. `nav_virtual_lanes` had 17 identical
files; the two C++ planner trees had three identical and two different files.
Hydrated image/mesh hashes were compared before removing any copy.

The nested source tree is the maintained integration tree, **not proof of the
canonical historical configuration of every paper run**. Root-only meshes were
relocated to it with identical LFS IDs. Differing scientific parameters and the
alternative planner were preserved in `historical/`, outside package discovery.
There are now three uniquely discovered packages.

**Actions:** 107 redundant paths removed; seven required meshes relocated;
29 historical files/variants relocated. No tracked build/cache/editor trash was
present at baseline. Generated colcon logs and bytecode remain ignored. No unique
world, geometry, waypoint or numerical scientific content was discarded.
